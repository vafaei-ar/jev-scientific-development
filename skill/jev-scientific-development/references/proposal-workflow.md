# Proposal workflow

## Specific Aims

Before calling JEV, map each aim to its hypothesis/question, data, method, outcome, and analysis. Then call `evaluate_proposal` with `section="specific aims"`.

If aim-method alignment is weak, fix the scientific mapping rather than polishing the prose.

## Significance and Innovation

Use JEV to challenge whether importance and novelty are actually established. Verify burden, gap, and novelty claims with literature rather than model judgment.

## Approach

Use JEV after the design is explicit enough to judge. Investigate concerns about feasibility, measurement, analysis, safety, or operational detail with domain evidence and actual protocol information.

## Final review

Run section-specific evaluations first. Use an overall proposal evaluation only after section-level problems have been addressed.
