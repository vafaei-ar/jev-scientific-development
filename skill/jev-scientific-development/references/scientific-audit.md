# Scientific writing audit

Use `audit_scientific_writing` to identify predefined prose risks, not to infer who wrote the text.

## Appropriate uses

- detect overly formulaic transitions or paragraph structures;
- flag vague academic language;
- identify unnecessary rhetorical symmetry or canned contrast constructions;
- assess clarity for an educated non-specialist;
- check whether tone is inflated relative to scientific evidence.

## Inappropriate uses

- claiming a passage was generated by AI;
- assigning an authorship probability;
- hiding or falsifying document provenance;
- replacing a substantive scientific review with style scoring.

When revising, preserve the author's actual voice and scientific meaning. Remove formulaic wording only when the replacement is clearer or more precise.
